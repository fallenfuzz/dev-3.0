Short: Run projects without git worktrees

A project can now switch its git workflow off (Project Settings → Board → Git workflow), so architecture, discovery and documentation work runs directly in the project folder: no worktree, branch, diff, PR or review columns, and finishing a task keeps every file. The Add Project dialog has the same Git workflow switch, so any folder, git repository or not, can be added that way, and an Operations task in a folder you chose no longer has every process in that folder killed when it finishes. dev3's Claude status hooks left in such a folder stay silent in a `claude` session started outside dev3, instead of printing a `dev3 task move` usage error on every prompt and tool call.
